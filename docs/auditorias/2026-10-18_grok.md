## Puntos de falla abiertos

### A. reanudar_flujo es incompleto
Hoy solo marca el estado como "en_progreso_reanudado" y devuelve el dict.
No continua ejecutando los pasos que faltan.
Es el hueco mas importante del ciclo de aprobacion.

### B. No hay checkpoint Git real en el runner
El README promete "Checkpoints Git antes de cada cambio".
En el runner actual no hay git add/commit ni snapshot de archivos antes de cada paso.

### C. aprobado_borrado sigue siendo self-declared
La propia tarea puede poner aprobado_borrado=True y saltarse la regla.

### D. flujos_pendientes vive solo en memoria del proceso
Si el proceso muere (o el cronjob termina), el flujo pendiente se pierde.

### E. El Auditor no usa LLM como segunda opinion
Solo reglas hardcodeadas. Esta bien para fail-closed, pero pierde cobertura semantica.
